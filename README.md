# CapitalBridge ONE

Integrated Enterprise Management & Global Mobility Platform for CapitalBridge Consultancy (Pty) Ltd.

## Status

Early-stage implementation. This repository is **not production-ready**.

## Product scope

Six linked domains: immigration and global mobility, business consultancy, IT services, engineering projects, training, and business administration/financial management.

## Financial foundation

The accounting engine is informed by the core principles of *Frank Wood's Business Accounting*, 15th edition: double entry, source journals, ledger, trial balance, bank reconciliation, financial statements, company accounts and financial analysis. The book is a reference for accounting principles, not a substitute for professional accounting or Lesotho legal/tax advice.

Implementation will proceed through reviewable pull requests, with transaction and security tests required before production deployment.
